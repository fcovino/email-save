Supporto

Risposte alle domande più frequenti. Se non trovi la soluzione, scrivi a assistenza@covino.partners indicando: versione di Outlook (sul web, nuovo Outlook o classico), il testo dell'errore e l'ora.

«Serve l'approvazione dell'amministratore»

Il componente agisce con i tuoi permessi su OneDrive e SharePoint e per questo chiede, al primo accesso, di consentire l'accesso ai file. Molte organizzazioni consentono questa approvazione solo a un amministratore. Succede una volta sola per tutta l'organizzazione.

Per l'amministratore

Accedi con un account amministratore globale (o amministratore di applicazioni) e apri questo link: Approva «Email Save» per l'organizzazione.

Permessi richiesti (delegati, cioè sempre limitati a ciò che l'utente già può fare): User.Read, Files.ReadWrite.All, Sites.Read.All. Il componente non legge la posta tramite Graph e non ha accesso senza un utente connesso. Puoi revocare l'accesso in Microsoft Entra ID → Applicazioni aziendali.

Non vedo il pulsante «Salva in SharePoint»

  • Apri un messaggio ricevuto: il pulsante compare nei messaggi letti, non nelle bozze.
  • Cerca il gruppo Email Save nella barra, oppure il menu … / App del messaggio.
  • Se il componente è stato assegnato dall'amministratore, può servire fino a 24 ore perché compaia. Riavvia Outlook.
  • Outlook sul web: se il tuo account non è Microsoft 365 con Exchange Online (per esempio un indirizzo IMAP collegato), i componenti non sono disponibili.

La finestra grande non si apre

Il componente prova ad aprire la finestra di scelta di sito e cartella. Se la tua versione di Outlook o il browser la bloccano (blocco popup, versioni molto vecchie), usa in automatico un selettore compatto dentro il pannello laterale: funziona allo stesso modo. Prova ad aggiornare Outlook o a consentire le finestre per il sito di Outlook.

Non trovo il mio sito SharePoint

  • Nella scheda Tutti digita parte del nome o dell'indirizzo: la ricerca interroga tutti i siti a cui hai accesso.
  • Per vederlo in Seguiti, apri il sito in SharePoint e scegli Segui.
  • I siti appena creati possono impiegare qualche minuto per comparire nella ricerca.
  • I siti a cui non hai accesso non vengono elencati.

«Accesso negato»

Non hai il permesso di aggiungere file in quella libreria (per esempio sei solo visitatore). Scegli un'altra cartella o chiedi al proprietario del sito di darti i permessi di modifica.

Il file esiste già

Prima di salvare scegli cosa fare: rinomina (aggiunge un numero al nome), sostituisci (crea una nuova versione del file esistente) oppure non salvare.

«Salva anche il testo dell'email (.eml)»

  • La voce è grigia, con la nota «Non disponibile in questa versione di Outlook.»: serve Outlook sul web, il nuovo Outlook per Windows o Outlook classico dalla versione 2404 (set di requisiti Mailbox 1.14). Aggiorna Outlook; gli allegati si salvano comunque.
  • Compare «Il testo non è quello di questa e-mail: non salvato.»: Outlook ha consegnato il testo di un'altra e-mail (può succedere se apri un'altra e-mail mentre il pannello è fissato e il salvataggio è in corso). Il file non è stato salvato, per non mettere nella cartella il testo sbagliato: premi di nuovo «Salva» restando su questa e-mail.

Revocare l'accesso

Da myapps.microsoft.com (utente) o da Microsoft Entra ID → Applicazioni aziendali (amministratore). Preferiti e cartelle recenti restano nelle impostazioni del tuo account Outlook: i preferiti si tolgono dal pannello con la stella; la copia locale si cancella eliminando i dati del sito dal browser.

Support

Answers to the most common questions. If you can't find a fix, write to assistenza@covino.partners with your Outlook version (web, new Outlook or classic), the error text and the time.

“Admin approval required”

The add-in acts with your own permissions on OneDrive and SharePoint, so at first sign-in it asks you to allow access to files. Many organizations let only an administrator approve this. It happens once for the whole organization.

For the administrator

Sign in with a Global Administrator (or Application Administrator) account and open this link: Approve “Email Save” for the organization.

Permissions requested (delegated, meaning always limited to what the user can already do): User.Read, Files.ReadWrite.All, Sites.Read.All. The add-in does not read mail through Graph and has no access without a signed-in user. You can revoke access in Microsoft Entra ID → Enterprise applications.

I can't see the “Save to SharePoint” button

  • Open a received message: the button appears on read messages, not on drafts.
  • Look for the Email Save group in the ribbon, or the message's … / Apps menu.
  • If an administrator assigned the add-in, it can take up to 24 hours to appear. Restart Outlook.
  • Outlook on the web: if your account is not Microsoft 365 with Exchange Online (for example a linked IMAP address), add-ins are not available.

The large window does not open

The add-in tries to open the site and folder picker window. If your Outlook version or browser blocks it (popup blocker, very old versions), it automatically uses a compact picker inside the side pane: it works the same way. Try updating Outlook or allowing popups for the Outlook site.

I can't find my SharePoint site

  • In the All tab type part of the name or address: the search queries every site you can access.
  • To see it under Following, open the site in SharePoint and choose Follow.
  • Newly created sites can take a few minutes to show up in search.
  • Sites you have no access to are not listed.

“Access denied”

You don't have permission to add files to that library (for example you are a visitor). Pick another folder or ask the site owner for edit permission.

The file already exists

Before saving, choose what to do: rename (adds a number to the name), replace (creates a new version of the existing file) or don't save.

“Also save the email text (.eml)”

  • The option is greyed out, with the note “Not available in this version of Outlook.”: you need Outlook on the web, the new Outlook for Windows or classic Outlook from version 2404 (requirement set Mailbox 1.14). Update Outlook; the attachments are saved anyway.
  • You see “The text is not from this email: not saved.”: Outlook handed over the text of another email (it can happen if you open another email while the pane is pinned and a save is running). The file was not saved, so that the wrong text never ends up in the folder: press “Save” again while staying on this email.

Revoking access

From myapps.microsoft.com (user) or Microsoft Entra ID → Enterprise applications (administrator). Favorites and recent folders stay in your Outlook account settings: remove favorites from the pane with the star; the local copy is deleted by clearing the site data in your browser.
